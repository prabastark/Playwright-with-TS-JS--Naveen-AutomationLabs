# Learn-Automation-Online

This repository contains small JavaScript learning files that explain basic programming concepts in a simple way.
Each file is written for beginners and includes comments to understand the idea quickly.

## Files in this repository

- `JavaScript/variables.js` — explains variables, scope, and `var`, `let`, `const`.
- `JavaScript/dataTypes.js` — explains primitive and reference data types in JavaScript.
- `JavaScript/conditions.js` — explains `if`, `else`, `else if`, `switch`, and nested conditions.
- `JavaScript/loops.js` — explains `for`, `while`, `do...while`, `for...of`, `for...in`, `break`, and `continue`.
- `JavaScript/demo.js` — a short starter example to run with Node.js.

## How to use

1. Open a terminal in this folder.
2. Run files with Node.js, for example:
   - `node JavaScript/variables.js`
   - `node JavaScript/dataTypes.js`
   - `node JavaScript/conditions.js`
   - `node JavaScript/loops.js`
   - `node JavaScript/demo.js`
3. Read the comments and change values to practice.

## Interview revision tips

- Learn the difference between `var`, `let`, and `const`.
- Know the 7 primitive JavaScript types and common reference types.
- Be able to explain `if/else` vs `switch`.
- Know when to use `for`, `while`, and `do...while` loops.
- Practice with simple examples by changing values and conditions.
